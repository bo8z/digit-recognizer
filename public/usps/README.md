# USPS browser dataset

The binary resources in this directory contain the canonical USPS handwritten
digit training and test splits published by the LIBSVM dataset repository:

- Source: https://www.csie.ntu.edu.tw/~cjlin/libsvmtools/datasets/multiclass.html#usps
- Training samples: 7,291
- Test samples: 2,007
- Image dimensions: 16 × 16 grayscale

`train.bin` and `test.bin` are compact browser resources generated by
`npm run prepare:usps`. Each file contains a 16-byte header, one unsigned-byte
label per sample, and 256 unsigned-byte grayscale pixels per sample.
